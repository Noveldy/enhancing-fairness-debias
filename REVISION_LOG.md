**Findings (complete test rows, 25 outer folds; reported as they are):**
- **Ablation, Adult: the resampling stage causes the larger sex gap; the cleaning stage does not.** Protected attributes kept: sex DP 0.171 (original) → 0.171 (cleaning only, Δ +0.000, p_Holm 0.96) → 0.199 (+ resampling, Δ +0.027 [0.022, 0.032], p_Holm < 1e-4). Sex EO 0.081 → 0.087 (n.s.) → 0.116 (Δ vs cleaning +0.029, p_Holm 0.0005). Same with protected attributes dropped (DP +0.023, EO +0.029, both significant). Mechanism: the selected resamplers are undersamplers (OneSidedSelection 18/25, TomekLinks 7/25 folds) that remove majority-class rows. Race gaps: no significant change in any stage.
- **Ablation, Bank:** no stage changes the marital gaps significantly. Resampling raises balanced accuracy by about 0.013 (significant only with marital dropped).

The paper's Adult/Bank schemas and synthetic CSVs were not stored, so `marginal_sampler` runs the **unchanged original code** on a schema derived from each training fold (categoricals/target: observed frequencies; numerics: `int` + `truncnorm` with the training mean, SD, min, max), seeded per call, with the global RNG state restored afterwards. `independent_marginals` samples each column from its exact training distribution (still independent). | R2 synthetic data (marginal-only sampling) |

| 5.2–5.3 code | `GaussianCopulaSampler`: own implementation (D3, numpy/scipy). One Gaussian copula per target × protected-attribute cell (Adult: income × sex; Bank: y × marital), cell shares kept exactly; empirical margins (exact inverse CDF, only observed values); categoricals mapped to CDF intervals ordered by frequency. Evaluation on the 25 outer folds (`experiments/synthetic_protocol.py`, `configs/synthetic.yaml`): generators fitted on complete training rows only; **TSTR** vs **TRTR** with the hyperparameters the Phase 3 `none` inner CV chose in the same fold (TRTR reproduces the Phase 3 predictions exactly, checked on folds with both int and float-stored parameters); **TSTS** = the original FSDG setup (train and test on synthetic). **Findings (25 outer folds; protected attributes as inputs unless noted; reported as they are):**
- **5.4: the marginal sampler destroys the predictive signal.** TSTR ROC AUC: Adult 0.465 (TRTR 0.916), Bank 0.492 (TRTR 0.726); balanced accuracy 0.50 in both. Models trained on it predict almost nobody positive (Adult 3.1%, Bank 0.3%), so every TPR and FPR is near 0 and the fairness gaps are near 0 (sex DP 0.009). This explains the old reports' near-identical TPR/FPR and DP ≈ 0.00004: a model that cannot separate the classes, not a fair one. The original setup (TSTS) gives AUC 0.50. `independent_marginals` behaves the same (AUC 0.51), so the cause is independent sampling, not the truncnorm schema. Independent sampling also erases the real differences in base rates between groups: P(income > 50K) is 0.247 for both sexes (real: women 0.114, men 0.312).
- **Gaussian copula:** TSTR AUC 0.905 vs 0.916 TRTR on Adult (−0.011, significant) and 0.715 vs 0.726 on Bank (n.s.). Balanced accuracy is slightly higher (+0.011 on Adult) because TSTR models predict more positives (0.244 vs 0.196). Calibration is worse (ECE 0.035 vs 0.013 Adult, 0.043 vs 0.009 Bank). Group base rates are kept (by construction of the cells). Sex DP gap 0.162 vs 0.171 (TRTR).
- **TSTS overstates utility:** Gaussian copula TSTS AUC is 0.951 on Adult (TSTR 0.905) and 0.753 on Bank (TSTR 0.715). The synthetic data are easier than the real data, so testing on synthetic rows (the original protocol) is not a valid estimate.
- **Marginal fidelity:** copula and independent marginals are at the sampling-noise floor (mean KS 0.007 vs 0.006 between real train and test). The marginal sampler is poor on zero-inflated or spiky columns: KS Adult capital-loss 0.95, capital-gain 0.92, hours-per-week 0.23; Bank pdays 0.81, previous 0.67, campaign 0.41, balance 0.26. Reason: a truncated normal cannot represent a point mass (e.g. >90% zeros, or pdays = −1 for clients never contacted), so KS ≈ the size of that mass. The generator offers no zero-inflated or mixture distribution, so a hand-written schema would hit the same limit.
- **Joint fidelity:** pairwise-dependence error (mean |Δ association|) Adult: copula 0.059, independent 0.153, floor 0.010; Bank: 0.069, 0.116, 0.011. The copula fails on deterministic relations: education ↔ education-num (association 1.0 real vs 0.14 synthetic), pdays ↔ previous ↔ poutcome (0.99 / 0.88 real vs 0.30). A classifier still tells copula rows from real ones (C2ST AUC 0.96 Adult, 0.93 Bank; 1.00 / 0.99 for the marginal sampler; floor 0.50). Per subgroup: the same pattern, weaker in small race groups (C2ST 0.92–0.96).
- **Privacy:** no generator copies records (0% exact matches; DCR to train = DCR to holdout; share of synthetic rows closer to train 0.50; MIA AUC 0.50 for all three). Limitations: one distance-based attacker, Gower distance, 2,000 queries; it does not rule out stronger attacks (e.g. shadow-model or attribute inference) and is not a formal guarantee such as differential privacy.
